# 🌦 Real-Time Weather Prediction System Using Machine Learning

A Machine Learning based Weather Prediction System that predicts tomorrow’s weather conditions using historical weather data and real-time weather API integration.

The system compares multiple Machine Learning models and automatically selects the best-performing model for prediction.

---

# 🚀 Features

- ✅ Real-Time Weather Data using Weather API
- ✅ Predicts Tomorrow Weather Conditions
- ✅ Multiple Machine Learning Models
- ✅ Automatic Best Model Selection
- ✅ Streamlit Web Application
- ✅ Historical Weather Dataset Training
- ✅ Accuracy Comparison Visualization
- ✅ Interactive User Interface

---

# 🧠 Machine Learning Models

- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier
- Logistic Regression

The system compares all models and selects the model with the highest accuracy automatically.

---

# 📊 Dataset Information

## Dataset Variables

- `date`
- `precipitation`
- `temp_max`
- `temp_min`
- `wind`
- `weather`

The dataset is used to train Machine Learning models to predict the next day's weather conditions.
